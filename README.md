# SmartCart App 🛍️✨

Desarrollo de una plataforma dinámica para la automatización de compras en línea, cálculo de presupuestos en tiempo real y gestión optimizada de productos.

### 🚀 Características del Proyecto:
* **Cálculo Automatizado:** Lógica avanzada para la actualización inmediata de subtotales, totales e impuestos según las interacciones del usuario.
* **Interfaz de Usuario Intuitiva:** Maquetación moderna y limpia orientada a mejorar la tasa de conversión y la experiencia de compra (UX/UI).
* **Persistencia y Control de Estados:** Manipulación precisa del DOM para agregar, editar o remover productos del carrito de forma fluida.

### 🛠️ Tecnologías utilizadas:
* HTML5 (Estructura semántica para e-commerce).
* CSS3 (Estilos modernos, Flexbox y diseño adaptivo).
* JavaScript puro (Lógica de programación, eventos y manejo de arreglos de datos).
